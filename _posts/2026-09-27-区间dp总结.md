## 1. 我对区间dp的理解
&emsp;&emsp;我对区间dp的理解个人感觉不是特别的深刻，因为题目做的不多，或者理解能力不足。首先区间dp的状态就是以区间的两个端点定义的，但不一定是表面的含义，在不同的题目中，区间的理解方式也要改变，比如[Sue的小球](https://vjudge.net/problem/%E6%B4%9B%E8%B0%B7-P2466)，这个题的区间实际是小球离散化的顺序，并不是$x$轴，而且这题的考法也很特殊。$dp[i][j]$的结果定义为啥呢？通常题目求啥就定义为啥，最后的结果输出大部分为$dp[1][n]$。或者$tot-dp[1][n]$。  
&emsp;&emsp;区间dp之所以成立，是因为问题由更小的区间构成（当然要分析），我们通过枚举区间的长度和起点来递推解决问题，甚至有时也要枚举区间的分割点，来获得区间的解。

## 2. 模板和常见转移方式
##### 1.枚举分割点转移
区间dp模板
```cpp
for(int len=2;len<=n;len++)
{
  for(int l=1;l+len-1<=n;l++)
  {
    int r=l+len-1;
    for(int k=l;k<r;k++)  //枚举分割点
    {
      dp[l][r]=min(dp[l][r],dp[l][k]+dp[k+1][r]+cost); 
    }
  }
}
```
题目：[石子合并](https://vjudge.net/problem/%E6%B4%9B%E8%B0%B7-P1880)，[Minimum Triangulation](https://vjudge.net/problem/CodeForces-1140D)。
##### 2.依据区间两侧元素转移
```cpp
for(int len=2;len<=n;len++)
{
  for(int l=1;l+len-1<=n;l++)
  {
    int r=l+len-1;
    if(s[r]==s[l]) dp[l][r]=dp[l+1][r-1];
    else dp[l][r]=min(dp[l][r-1],dp[l+1][r]);
  }
}
```
题目：[构造回文串的最小插入次数](https://www.luogu.com.cn/problem/P1435)，[取数游戏](https://www.luogu.com.cn/problem/P1005)，[每次删除回文串的最小删除次数](https://vjudge.net/problem/CodeForces-607B)

##### 3.依据区间相邻元素元素转移
```cpp
for(int len=2;len<=n;len++)
{
  for(int l=1;l+len-1<=n;l++)
  {
    int r=l+len-1;
    for(int k=l;k<r;k++)
    {
      if(dp[l][r]&&dp[l][k]==dp[k+1][r])
      {
        dp[l][r]=max(dp[l][r],dp[l][k]+1);
        ans=max(ans,dp[l][r]);
      }
    }
  }
}
```
题目：[合并相邻数字获取最大值](https://www.luogu.com.cn/problem/P3146)，[数组最短压缩长度](https://vjudge.net/problem/CodeForces-1312E#author=main)。

##### 4.依据区间一侧元素和区间中的元素转移
```cpp
for(int len=2;len<=n;len++)
{
  for(int l=1;l+len-1<=n;l++)
  {
    int r=l+len-1;
    dp[l][r]=dp[l][r-1]+1;
    for(int k=i;k<r;k++)
    {
      int left=(k==i)?(0:dp[l][k-1])
      if(s[r]==s[k])
        dp[l][r]=min(dp[l][r],dp[k][r-1]+left)
    }
  }
}
```
题目：[涂色问题](https://vjudge.net/problem/%E6%B4%9B%E8%B0%B7-P4170)，[删除字符串](https://vjudge.net/problem/CodeForces-1132F#author=translator:1281309:zh)
这两个问题想多说一句，关键是转移方程的推导，第一个看看到底可以怎么涂，要么分开涂，两边相加，要么发现有一侧可以白嫖一笔，少涂一次。  
第二个也是，要么分开删除，要么发现有两个元素相同，可以白嫖一次删除次数。

##### 5.依据元素位置转移
我个人感觉这个题不像区间dp了，或者说区间dp只是题目的一部分，它更像一般性dp转移，依据题目分析转移方式然后得出转移方程，最后求解。
```cpp
 for (int len = 2; len <= n + 1; len++)
    {
        for (int i = 1; i + len - 1 <= n + 1; i++)
        {
            int j = i + len - 1;
            int unused1=pre_sum[i]+pre_sum[n+1]-pre_sum[j];
            f[i][j] = min(f[i][j], f[i + 1][j] + (unused1) * (a[i + 1].x - a[i].x));
            f[i][j] = min(f[i][j], g[i + 1][j] + (unused1) * (a[j].x - a[i].x));

            int unused2=pre_sum[i-1]+pre_sum[n+1]-pre_sum[j-1];
            g[i][j] = min(g[i][j], g[i][j - 1] + (unused2) * (a[j].x - a[j - 1].x));
            g[i][j] = min(g[i][j], f[i][j - 1] + (unused2) * (a[j].x - a[i].x));
        }
    }
```
题目：[Sue的小球](https://vjudge.net/problem/%E6%B4%9B%E8%B0%B7-P2466)
这题我想多说说，首先他的状态定义就不同，$f[i][j]$表示搜集完$[i,j]$这一段并且停在$i$处损失的分数，$g[i][j]$表示搜集完$[i,j]$这一段并且停在$j$处损失的分数，为什么会如此定义呢？很简单，你移动的情况就4种，向右或者向左搜集一个元素，或者向左或者向右跨一段距离搜集元素。所以四个转移方程可以描述所有移动情况，又可以由小区间递推到大区间。  
第二个可以说的点就是它定义的结果是损失的分数而不是获得的分数，我们无法定义获得的分数，因为他随时间变化，我们如果要合并一个一区间时，我们并不知道何时合并他，因此不知到它的分数，破坏了无后效性这一点。而如果我们定义除了该区间损失的分数，那么就满足了无后效性，因为在此前损失的分数全都被记录了，我们只要考虑该次移动损失的分数，加上就行。  
给我的一个思考就是如果定义的状态不满足无后效性，我们可以把破坏无后效性的因素作为状态的定义（把它提前计算）。
