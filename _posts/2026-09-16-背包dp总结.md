最近在[vjudge](https://vjudge.net)上做了一些关于背包类型的动态规划，总结一下。

### 1. 0/1背包

&emsp;&emsp;0/1背包可以说是最简单的一类背包问题了，题目通常是给定$n$件物品，然后给出每个物品的价值$val$和重量$cost$（耗费）。然后让我们在给定的总容量$total$选择一些物品，不能重复选，使获得的物品总价值尽可能地大，通常有如下做法。

1. 暴力的做法就是可以遍历所有合规的物品集合，然后求出最大值，可以用递归实现，复杂度在$O(n*2^n)$。
2. 使用动态规划做法，可以设$dp[i][j]$表示前$i$件物品，容量为$j$是获得的最大价值，复杂度在$O(total*n)$，空间复杂度$O(n*total)$。
3. 方法2的优化就是使用倒序遍历，0/1背包的一个关键特征就是物品不能重复选，如果我们压缩空间后还正向遍历很可能遇到重复选择同一个物品的问题。  
4. 常见有如下做法。
> 题目链接：[采药](https://www.luogu.com.cn/problem/P1048)

```cpp
#include<bits/stdc++.h>
using namespace std;
//暴力枚举
int solve1()
{
  int w[20],v[20],ans=-1;
  for(int mask = 0; mask < (1<<n); mask++)
  {
    int val=0,cost=0;
    for(int i=0; i < n; i++)
    {
      if(mask & (1<<i))
      {
        val+=v[i];
        cost+=w[i];
      }
      if(cost>total) break; 
    }
    ans=max(ans,val);
  }
  return ans;
}

//二维dp
int solve2()
{
  int dp[n + 1][total + 1]={INT_MIN}; //语法有错，简化一下
  dp[0][0]=0;
  for(int i = 1;i <= n;i++)
  {
    for(int j = 0;j <= total;j++)
    {
      dp[i][j]=dp[i - 1][j];
      if(dp[i - 1][j - w[i]] != INT_MIN && j >= w[i]) 
        dp[i][j]=max(dp[i][j],dp[i - 1][j - w[i]] + val);
    }
  }
  int ans = -1;
  for(int j = 0; j <= total; j++) ans=max(ans, dp[n + 1][j]);
  return ans;
}
//一维空间优化
int solve3()
{
  int dp[n+1]={INT_MIN};
  dp[0] = 0;
  for(int i=1;i<=n;i++)
  {
    int cost = w[i];
    int val = v[i];
    for(int j=total;j>=cost;j--)
    {
      if(dp[j-cost]!=INT_MIN) dp[j] = max(dp[j],dp[j-cost]);
    }
  }
}
int main()
{
  return 0;
}
``` 

### 2. 带附件的背包
&emsp;&emsp;分组背包就是0/1背包的变形，也很好理解，就是物品选择变为主件与附件，如果要选附件，必须先选主件，对于主件并不多的情况，可以把他转换为0/1背包，就是只选主件，选择主件和附件一或附件二，或者都选，这样分为4个互不相干的组，进行0/1背包。
>题目链接：[预算方案](https://www.luogu.com.cn/problem/P1064) 

### 3. 完全背包
&emsp;&emsp;完全背包就很简单了，就是物品可以是无限数量，直接就是一维数组顺序迭代就好。
```cpp
void solve()
{
  vector<int> dp(n+1,0);
  for(int i=1;i<=n;i++)
  {
    int cost = w[i];
    int val = v[i];
    for(int j=cost;j<=total;j++)
    {
      if(dp[j-cost]!=INT_MIN)
        dp[j]=max(dp[j],dp[j-cost]+val);
    }
  }
}
```
### 4. 多重背包
&emsp;&emsp;多重背包也是0/1背包的变形，就是物品是有一定数量的。
1. 比较暴力的做法是是把相同的物品分为一个组，遍历每个组，对组内的物品进行一次0/1背包，时间复杂度大概$O(n^3)$。(这里的写法有错，具体复杂度根据题目数据和范围，这里做简化处理)。
2. 二进制拆分优化，把每个物品的数量$s_i$拆为二的幂（1，2，4，···）,能拆分的原理就是任何数都可以用二进制表示，然后对每个组进行0/1背包，时间复杂度在$(n*m*logs)$。
3. 最优做法是进行单调队列优化，复杂度在$O(m*n)$，常数较大。（不太懂，以后仔细研究）
>[!TIP]
>
>这里想讲一下循环层级问题，如果容量在外倒序迭代，物品在内层迭代，这就是分组背包的实现，不选相同的物品，下一组物品迭代时，只会有上一组的一个物品。
>如果两者反过来，就是0/1背包的实现，在物品组内可以选择多个物品
